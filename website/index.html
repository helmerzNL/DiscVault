Self-hosted media tooling for collectors

Your shelf is physical. Your catalog should be fast.

DiscVault is a modern collection manager for 4K UHD, Blu-ray, and DVD. Scan barcodes, enrich metadata, browse beautifully, and integrate with MCP-enabled workflows.

Get DiscVault How to deploy
  • Barcode scanner + manual entry
  • OMDb and TMDb metadata fallback
  • Backup, restore, and logs
  • MCP endpoint for AI workflows

Features

Built for people with real shelves, real stacks, and real editions.

Scan and enrich

Use your camera to scan barcodes, then automatically pull movie metadata and cover art.

Filter and search

Search by title, genre, or director and filter by format in a clean collection view.

Safe by design

Run self-hosted, control your own data path, and keep snapshots with built-in backup and restore.

MCP ready

Connect AI assistants to your library through DiscVault's MCP endpoint for automation and search.

Deployment

Deploy on Unraid or run it anywhere Docker runs.
